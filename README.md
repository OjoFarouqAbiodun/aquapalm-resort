# AquaPalm Resort & Spa — Luxury Landing Page

A premium, high-ticket luxury resort landing page concept built to demonstrate fluid typography, pixel-perfect design-to-code execution, and lightweight interaction workflows.

## 🎨 Design Credit
- **UI/UX Designer:** [Damilare Kolawole](https://linkedin.com) 🙇‍♂️
- **Design Link:** [Figma Project File](https://figma.com)

## 🛠️ Tech Stack & Methodology
- **Semantic HTML5:** Clean, search-engine-optimized structure without redundant framework containers.
- **Custom Modern CSS:** Responsive fluid layouts utilizing CSS Custom Properties (variables) and dynamic scaling (`clamp()`).
- **Vanilla JavaScript:** A lightweight, pure interaction loop managing the interactive hero slider mechanics, active indicator states, and synchronized autoplay intervals—running 100% dependency-free.

## 🚀 Key Features Built From Scratch
- Floating glassy navigation header layout depth control (`z-index`).
- Hardware-accelerated horizontal slide transitions using CSS transforms (`translateX`).
- Double-loop pagination controls supporting parallel automated intervals and user click overrides.
